## Переход с 1.4.93

Сохраните старое окружение, входные данные и результаты, если нужно
воспроизводить эксперименты 1.x. Для современного пакета создайте отдельное
окружение CPython 3.10–3.13. Вместо изменяемого объекта генератора используйте
`GenerationConfig` и `Generate(config)`. В CLI перейдите со старых флагов
на подкоманду `generate`. Перед вызовом `validate` или `chart` приведите
файлы к каноническому формату OHLCV в UTC с заголовком
`datetime,open,high,low,close,volume`. Старое начальное значение ГПСЧ
относится к старой модели. Для серии v2 сохраните новый манифест.
[Контракт данных](../../../data-contract.md) · [Миграция API и графиков](../../../chart-migration.md)

## Переход с тестового v2.0.0

Сохраните манифесты и окружение тестовой версии для точного повторения
её запусков. При проверке 2.1 сгенерируйте серию из той же конфигурации
в чистом окружении и сравните отпечатки OHLCV. Файлы графиков проверяйте
отдельно. Базовый пакет экспортирует автономные SVG и интерактивные HTML.
Для автоматизации используйте `--no-view` в CLI или `view=False` в Python.
Для PNG и JPEG потребуется соответствующее дополнение `export`.
[Допущения и ограничения модели](../../../model-regime-v2.md)

## Проверка серии с фиксированным начальным значением

Установите пакет из [архива версии 2.1](release-2-1.md) и выполните команды
в новом каталоге.

```sh
python -I -m pricegenerator generate --seed 42 --horizon 240 --start 2025-01-06T00:00:00Z --timeframe-seconds 60 --output prices.csv --manifest scenario.json
python -I -m pricegenerator validate prices.csv --timeframe-seconds 60 --no-gaps
python -I -m pricegenerator replay scenario.json --output replay.csv
python -I -m pricegenerator chart prices.csv --output chart.html --no-view
python -I -m pricegenerator chart prices.csv --output chart.svg --no-view
```

Проверка должна подтвердить корректность 240 строк. В зафиксированном
окружении файлы `prices.csv` и `replay.csv` совпадают побайтно.
В [анимации CLI](../../../examples/cli-demo.md) используется другая серия
2.0.0. В описании приведены команды, параметры экспорта и шаги воспроизведения.
