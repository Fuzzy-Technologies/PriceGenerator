[English](../en/migrate-to-2-1.md) · [简体中文](../zh-CN/migrate-to-2-1.md)

| Версия   | Где искать и для чего использовать                                                                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------- |
| `1.4.93` | Версия на PyPI. С неё можно перенести скрипты и тесты с API 1.x.                                                     |
| `v2.0.0` | Тестовый тег на GitHub для воспроизведения исходных примеров 2.x, коммит `83b1b75a99be06947a93314d6c2509a257ed6b3e`. |
| `v2.1.0` | Предрелиз на GitHub с ансамблями Монте-Карло и необязательной нечёткой диагностикой.                                 |

## Если ваш проект на 1.4.93

Для повторения старых экспериментов сохраните окружение 1.x вместе с данными
и результатами. Для ветки 2.x создайте отдельное окружение с CPython 3.10–3.15.
Вместо настройки полей генератора соберите `GenerationConfig` и передайте
его в `Generate(config)`. В командной строке используйте подкоманду
`generate` вместо прежних флагов запуска.

Перед вызовом `validate` или `chart` приведите исходный CSV к формату OHLCV
в UTC с заголовком `datetime,open,high,low,close,volume`. Один и тот же
`seed` в разных моделях может давать разные ряды. Для нового ряда
сохраните манифест.
[Формат OHLCV](../../../data-contract.md) ·
[Переход на новый API графиков](../../../chart-migration.md)

## Если вы уже пользовались тестовой версией 2.0

Манифесты 2.0 и соответствующее окружение нужны для точного повторения
прежних прогонов. Для сверки между версиями сгенерируйте ряд в 2.1 из той же
конфигурации и сравните контрольные хеши OHLCV. Экспорт графиков проверяйте
отдельно. HTML и SVG доступны в базовой установке, а для PNG и JPEG нужен
`[export]`. В автоматических прогонах указывайте `--no-view` в CLI
или `view=False` в Python.
[Допущения модели](../../../model-regime-v2.md)

## Контрольный прогон с фиксированным seed

Установите пакет из [архива 2.1](release-2-1.md) в отдельное окружение и выполните команды
в новом каталоге. В быстром старте приведён порядок установки на примере
тестового тега 2.0.
[Установка из исходников](../../../../README_RU.md#установка) ·
[Быстрый старт](quick-start.md)

```sh
python -I -m pricegenerator generate --seed 42 --horizon 240 --start 2025-01-06T00:00:00Z --timeframe-seconds 60 --output prices.csv --manifest scenario.json
python -I -m pricegenerator validate prices.csv --timeframe-seconds 60 --no-gaps
python -I -m pricegenerator replay scenario.json --output replay.csv
python -I -m pricegenerator chart prices.csv --output chart.html --no-view
python -I -m pricegenerator chart prices.csv --output chart.svg --no-view
```

Ожидаемый результат — 240 корректных строк, а при повторе в том же окружении
файлы `prices.csv` и `replay.csv` совпадают побайтно. В анимации командной
строки показан отдельный прогон на 2.0.0, для которого приведены команды
и параметры экспорта.
[Запись прогона 2.0](../../../examples/cli-demo.md)
