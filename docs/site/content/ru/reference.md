# Справочник по котировкам и графикам
{: id="справочник-по-свечным-данным" }

## Формат CSV и единицы объёма
{: #csv }

Первая строка файла — `datetime,open,high,low,close,volume`. Каждая следующая строка описывает одну свечу. Время открытия указывается в UTC. Метки идут по возрастанию и не повторяются. Если в выгрузке брокера время записано без смещения, задайте исходный часовой пояс параметром `validate --timezone`. Цены открытия и закрытия должны лежать между минимумом и максимумом свечи. Для участка с непрерывными часовыми торгами флаги `--timeframe-seconds 3600 --no-gaps` позволяют проверить, что ни один час не пропущен.

В стандартном сценарии поле `volume` содержит целое число — условную меру торговой активности за время свечи. В данных с биржи смысл поля определяет источник. Это могут быть, например, акции в штуках или объём в BTC с дробной частью. При импорте дробная часть сохраняется. Чтобы Python записал сгенерированные целые объёмы в том же виде, что и командная строка, используйте `WriteCSV(candles, "candles.csv", volume_as_count=True)`.

## Графики и индикаторы
{: #charts }

```sh
python -m pricegenerator chart candles.csv --analysis --output chart.html --view
```

На обычном графике видны свечи и объём. Флаг **`--analysis`** открывает доступ к индикаторам и подробной статистике. В разделе **Indicators** выберите **SMA 50 / 200**, чтобы сравнить две простые скользящие средние цен закрытия. Для значения на 200-й свече нужны все 200 закрытий. **Bollinger bands** показывает полосы Боллинджера вокруг средней цены, **Midpoint** отмечает середину диапазона каждой свечи — `(high + low) / 2`.

**Close limits and trends** отмечает высшую и низшую цены закрытия за весь ряд и соединяет первое закрытие с последним. **Zig-Zag** показывает развороты, подтверждённые последующими свечами. Эти линии удобны для разбора завершённых движений. В историческом тесте сигнал на вход должен опираться только на те данные, которые уже были доступны к этому моменту.

Колёсико мыши меняет масштаб, а **Box zoom** увеличивает выделенный участок. **Export PNG** сохраняет видимые свечи, объёмы и выбранные индикаторы. Базовой установки достаточно для HTML и SVG. Для записи PNG или JPEG непосредственно из Python или командной строки установите `pricegenerator[export]`. При статическом экспорте с `--analysis` под графиком также появится полный статистический отчёт.

## Доходности и просадка
{: #analysis }

Команда `python -m pricegenerator analyze candles.csv --output stats.json` рассчитывает доходности, объёмы, число растущих и падающих свечей, характеристики распределений и зависимости между наблюдениями. Просадка **цены** по закрытиям — это падение относительно самого высокого закрытия, достигнутого к данному моменту. Если цена после максимума 100 закрылась на 80, просадка составляет 20%. Для просадки торгового счёта понадобятся история сделок и стоимость портфеля с учётом издержек. Если какую-либо величину вычислить нельзя, причина указана в отчёте.

## Параметры модели
{: #model }

Дрейф и волатильность задаются на одну свечу. Команда, которая меняет интервал с минуты на час, меняет только расстояние между временными метками. Для часовых доходностей параметры нужно подбирать отдельно. Расписание биржи, спред, сделки внутри свечи и исполнение ордеров модель не воспроизводит. [Как строятся свечи и рассчитывается объём](https://fuzzy-technologies.com/PriceGenerator/ru/scenario-guide/)

## Оценка параметров и диагностика
{: #research }

В Python можно оценить параметры модели по одному участку истории и проверить их на другом. В [примере Bitstamp](https://fuzzy-technologies.com/PriceGenerator/ru/experiments/#bitstamp) настроили дрейф, волатильность и средний объём. При выбранных настройках объём в каждом часу равнялся среднему за период подгонки. Дополнительная нечёткая диагностика на CPython 3.13–3.15 показывает, как волатильность и активность соотносятся с опорными значениями. Оценка рассчитывается отдельно и не управляет генератором свечей.

## Как оценить сходство с рынком
{: #validation }

Сначала выберите свойство, существенное для задачи. Например, для стратегии на всплесках объёма важно, как часто возникает всплеск и с каким движением цены он совпадает. Одного совпадения средних объёмов недостаточно. Задайте допуски на первом отрезке истории, затем проверьте их на следующем, сохранив те же настройки. Для повторной проверки сохраните `seed`, манифест и контрольную сумму свечей.

## Установка из готового пакета
{: #packaging }

[На PyPI](https://pypi.org/project/pricegenerator/2.2.1/) доступны wheel и архив исходников. Обе сборки проверяются установкой в чистое окружение. Команда `python -m pip install pricegenerator==2.2.1` установит версию из примеров. Для прямого экспорта в PNG или JPEG используйте `python -m pip install "pricegenerator[export]==2.2.1"`.
