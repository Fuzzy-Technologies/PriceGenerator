# Справочник по свечным данным

## Формат CSV и объём
{: #csv }

Заголовок файла — `datetime,open,high,low,close,volume`. Метки времени уникальны, идут по возрастанию и приведены к UTC. Если брокер записал время без смещения, укажите часовой пояс при импорте. Максимум и минимум свечи должны охватывать открытие и закрытие. Чтобы дополнительно проверить часовую сетку без пропусков, передайте `--timeframe-seconds 3600 --no-gaps`.

Базовая модель генерирует целочисленный показатель активности. При импорте количество актива может быть дробным и сохраняет исходные единицы. Чтобы из Python записать целые объёмы в точности в том же виде, что и CLI, используйте `WriteCSV(candles, "candles.csv", volume_as_count=True)`.

## Графики и индикаторы
{: #charts }

На базовом графике видны свечи и объёмы. С флагом `--analysis` появятся переключатели индикаторов и раскрываемая статистика. Для SMA 200 нужны хотя бы 200 свечей. Полосы Боллинджера показывают коридор вокруг скользящей средней. Midpoint отмечает середину между максимумом и минимумом свечи. Линии предельных закрытий, тренд между концами ряда и Zig-Zag используют последующие бары для описания уже завершённого движения.

```sh
python -m pricegenerator chart candles.csv --analysis --output chart.html --view
```

Приблизьте интересующий участок колесом или рамкой. **Export PNG** сохранит текущий вид со включёнными индикаторами. Для прямого экспорта в PNG/JPEG установите `pricegenerator[export]`. При статическом экспорте с `--analysis` под рисунком появится полный отчёт. SVG и офлайн-HTML работают в базовой установке.

## Разброс и просадка
{: #analysis }

Команда `python -m pricegenerator analyze candles.csv --output stats.json` считает направления свечей, доходности, объёмы, крайние значения и связи внутри ряда. Ценовая просадка по закрытиям показывает снижение от предыдущего пика до последующего закрытия. Для просадки счёта нужны позиции стратегии и издержки сделок. У неопределённых показателей в отчёте указана причина.

## Настройки модели
{: #model }

Дрейф и волатильность задаются на одну свечу. При переходе от минут к часам изменится шаг меток времени. Для нового интервала отдельно подберите масштаб движения цены. Генератор создаёт свечи и счётчик активности. Календарь биржи, спред, тики внутри свечи и исполнение ордеров требуют отдельных данных. [Как строятся свечи и объёмы](https://fuzzy-technologies.com/PriceGenerator/ru/scenario-guide/).

## Исследовательские возможности
{: #research }

Через Python можно оценить выбранные параметры на раннем периоде и проверить их на следующем. В варианте подгонки с непрерывным объёмом активность зафиксирована на среднем уровне. Дополнительная нечёткая диагностика для CPython 3.13–3.15 выставляет оценку по волатильности и активности. Она рассчитывается отдельно от генерации цен. [Результаты проверки на BTC/USD](https://fuzzy-technologies.com/PriceGenerator/ru/experiments/#bitstamp).

## Сборка и проверка
{: #development }

Установите локальную копию командой `python -m pip install .`. Для сборки справочника публичного Python API установите `.[docs]` и выполните `python PDocBuilder.py` из корня проекта. Справочник откроется из `build/docs-api/pricegenerator.html`. В старой версии был изменяемый объект генератора и другие флаги CLI. [Как перенести свой скрипт](https://fuzzy-technologies.com/PriceGenerator/ru/migration/).


## Как проверять результат
{: #validation }
Отдельно проверьте формат CSV, распределения и зависимости между барами. Даже при близкой волатильности объёмы и чередование резких движений могут расходиться. Задайте допуски на ранних данных и проверьте их на следующем периоде. Сохраните seed, манифест и контрольный отпечаток ряда.

## Установка и выпуск пакета
{: #packaging }
Проект собирает wheel и архив исходников. Перед одобренной публикацией в PyPI их устанавливают в чистых окружениях, а исходный коммит отмечают тегом. Для офлайн-HTML и SVG достаточно базового пакета. Для PNG и JPEG добавьте опцию export.
