# Синтетические сценарии OHLCV и границы их применимости

[English](../en/scenario-guide.md) · [简体中文](../zh-CN/scenario-guide.md)

В [быстром старте](quick-start.md) показано, как сгенерировать,
воспроизвести и экспортировать минутные свечи на проверенной тестовой
версии 2.0 с GitHub. [Руководство по миграции](migrate-to-2-1.md)
описывает изменения в предварительном выпуске 2.1.0 на GitHub.

## Как читать свечи

Таблица обмена содержит шесть столбцов в порядке
`datetime,open,high,low,close,volume`. Метки времени уникальны,
строго возрастают и хранятся в UTC с наносекундной точностью. Цены и
объём представлены конечными числами binary64. Объём неотрицателен,
максимум и минимум свечи охватывают цены открытия и закрытия.
Функция чтения допускает неположительные цены, если выполнены условия
на геометрию свечи. Генератор по умолчанию выдаёт положительные цены.

Чтобы проверить равномерность сетки, явно задайте интервал. Для данных
брокера укажите часовой пояс меток без смещения и сохраните фактические
разрывы. Разбор и проверка описаны в [контракте CSV](../../../data-contract.md).
Для MT5 см. [пример обмена](quick-start.md#обмен-барами-с-metatrader-5):
выравнивание по M1, целочисленные поля объёма и спред. Для тестирования
стратегии на реальных тиках нужна отдельная тиковая история.

## Как устроен сценарий

Модель `regime_v2` начинает с режима низкой волатильности. Перед каждой
свечой она переключается между низкой и повышенной волатильностью с
вероятностью `1 - regime_persistence`. Стандартное отклонение
гауссовской составляющей доходности $\sigma$ равно `volatility` в спокойном режиме и
`volatility * regime_scale` в режиме повышенной волатильности.
Параметры заданы на одну свечу. При смене интервала подбирайте их
для новой частоты.

Предлагаемая логарифмическая доходность равна
$r = \mu + \sigma Z + \sigma_0 s B Z_{\mathrm{shock}}$.
Здесь $\mu$ — `drift`, $\sigma_0$ — базовая `volatility`,
$s$ — `shock_scale`. Нормальные величины независимы. Независимая
величина Бернулли $B$ активирует скачок с вероятностью
`shock_probability`. Начиная со второй свечи цена открытия равна
предыдущей цене закрытия. Если предлагаемая логарифмическая цена
закрытия выходит за заданные границы, модель отражает её от них.
Поэтому фактическая доходность может отличаться от $r$.

Тени удлиняют тело свечи в логарифмической шкале цены. События
аномального удлинения верхней и нижней тени независимы, а сами тени
обрезаются по заданным границам. Объём моделируется как непрерывная
мера активности с автокоррелированным шумом в логарифмической шкале
и настраиваемой зависимостью от величины фактической доходности.
[Спецификация модели](../../../model-regime-v2.md) содержит точные
формулы, порядок случайных выборок и правила обработки границ.
[Численные тесты](../../../../tests/test_regime_v2_oracles.py) проверяют
случаи с вручную рассчитанными значениями.

## Как проверить результат и сохранить его происхождение

Выполните из каталога примера быстрого старта:

```sh
python -I -m pricegenerator analyze prices.csv --output statistics.json
python -I -m pricegenerator chart prices.csv --output analysis.html --analysis --no-view
```

Первая команда сохраняет статистики и указывает, какие оценки
не определены. Вторая создаёт автономный HTML-график с индикаторами
и диагностикой. Откройте его локально. В [руководстве по анализу](../../../analysis.md)
перечислены метрики и условия их применимости.

Сохраните тег или коммит, точную конфигурацию и seed, манифест, команду,
версии зависимостей и SHA-256 каждого экспортированного файла. Отпечаток
в манифесте идентифицирует канонические свечи. Хеш экспорта относится к
байтам файла и может зависеть от среды рендеринга. В примерах
[рыночного графика](../../../examples/modern-market.md) и
[выравнивания индикаторов](../../../examples/modern-indicator-alignment.md)
описано, как данные были получены и преобразованы.
У [анимированного примера CLI](../../../examples/cli-demo.md) собственный
набор из 120 свечей, команды и описание происхождения.

## Где уместны исследовательские API

- [Калибровка, бутстрэп и заданные стресс-сценарии](../../../research-models.md)
  доступны через экспериментальные API модулей. Для них приведены
  воспроизводимые примеры на синтетических данных.
- В разделе [Монте-Карло](../../../monte-carlo.md) описаны экспериментальный
  ансамбль с заданным seed и квантили цены для каждого шага. Эти
  квантили зависят от модели. Интервал на отдельном шаге не задаёт
  покрытие траектории целиком.
- [Нечёткая диагностика](../../../fuzzy-diagnostics.md) — экспериментальное
  опциональное расширение для Python 3.13. Скалярная оценка обобщает
  переданные отношения волатильности и активности. Она не влияет на
  генерацию свечей.
- [Сравнение с референсными данными](../../../reference-comparison.md)
  фиксирует происхождение, допущения и ограничения исторического
  примера. Геометрию свечей, распределения отдельных показателей
  и зависимости проверяют раздельно. Критерии для более сильных
  утверждений описаны в [правилах статистической проверки](../../../adr/0005-statistical-validation-and-realism-claims.md).

Модель по умолчанию подходит для контролируемых тестов потребителей
OHLCV и стресс-сценариев. В ней отсутствуют книга заявок, спред,
исполнение ордеров и биржевой календарь. По её результатам нельзя
установить качество прогноза или доходность стратегии.

Из того же дерева исходников соберите [справочник публичного Python API](../../../development.md#build-the-public-api-reference).
Он покажет корневые экспорты и сигнатуры.
